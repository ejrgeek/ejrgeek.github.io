# Flash CNH - Landing Page

Repositório contendo a landing page oficial do aplicativo **Flash CNH**, projetada para apresentar os recursos do app e disponibilizar os links oficiais de download, Políticas de Privacidade e Termos de Uso.

## Sobre o Projeto

O Flash CNH é um aplicativo de apoio aos estudos para exames teóricos de habilitação (CNH), oferecendo recursos como:
- Estudo por módulos oficiais
- Flashcards objetivos
- Quizzes com feedback imediato
- Simulados configuráveis

Esta landing page foi desenvolvida para ser rápida, responsiva e acessível, refletindo a clareza e objetividade do aplicativo.

## Tecnologias Utilizadas

- HTML5 semântico
- CSS3 (Variáveis, Grid, Flexbox, Animações)
- JavaScript Vanilla para interações
- Design responsivo e acessível
